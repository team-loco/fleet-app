# Keyboard shortcuts

Generated from the binding table in `crates/fleet-ui/src/keymap.rs`; run `mise run gen:keys` after changing it. The same table binds the keys and draws the Keyboard shortcuts section of Settings (⌘,).

## General

| Keys | Action |
|---|---|
| ⌘P | Quick open: resources, clusters and pages |
| ⌘⇧P | Run a command |
| ⌘K | Command palette |
| ⌘⇧C | Switch cluster |
| ⌘, | Settings |
| ⌘N | New window |
| ⌘W | Close the inspector, then the dock, then the window |
| ⌘Q | Quit Fleet |

## View

| Keys | Action |
|---|---|
| ⌘B | Toggle the sidebar |
| ⌘J | Toggle the bottom dock |
| ⌘1 | Focus the sidebar |
| ⌘2 | Focus the page's list |
| Tab / ⇧Tab | Next or previous focus area |
| / | Focus the page filter |
| ⌘F | Focus the page filter |

## Navigate

| Keys | Action |
|---|---|
| ⌘[ | Back |
| ⌘] | Forward |
| ⌃Tab | Next recent page |
| ⌃⇧Tab | Previous recent page |

## Lists and tables

| Keys | Action |
|---|---|
| ↑ / ↓ | Move the selection |
| Home / End | First or last row |
| PgUp / PgDn | Move a page |
| letters | Jump to the row whose name starts with them |
| ↵ | Open the selected row |
| Esc | Close the inspector |
| ⌘. | Cluster actions in the switcher |
